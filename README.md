# TrustVault

TrustVault is a secure document-sharing platform designed to
prevent unauthorized document access and maintain a reliable
audit trail of document activities.

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: PostgreSQL
- Version Control: Git and GitHub

## Main Features

- User authentication and role-based access
- Secure document upload and management
- Document-level read and edit permissions
- Access granting and revocation
- Document activity audit trail
- Security testing
